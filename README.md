# kos-tool

Releases of kos-tool, the command-line tool for the KOS SDK.

## Install

Install latest:
```sh
curl -fsSL https://raw.githubusercontent.com/Kry10-NZ/kos-tool-publish-site-test/refs/heads/main/install.sh | sh
```
Install a specific version
```sh
curl -fsSL https://raw.githubusercontent.com/Kry10-NZ/kos-tool-publish-site-test/refs/heads/main/install.sh | sh -s -- --version <version>
```
